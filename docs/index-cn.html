7 使用教程

手把手教你从零开始。

运行一键安装器

Windows 打开 PowerShell，macOS/Linux 打开终端，粘贴安装命令回车。等待自动安装依赖（Node.js、Git、Python）。

在菜单中选择工具

安装器会显示菜单，输入数字选择要安装的 AI 工具。推荐先安装 [1] Ollama（本地大模型，完全免费）。

下载 AI 模型（Ollama 用户）

安装 Ollama 后，运行 ollama pull qwen2.5:7b 下载推荐模型。首次下载需要几分钟（约 4.7GB）。

安装编程插件（可选）

如果需要 AI 辅助编程，在菜单中选择 [3] Continue。安装后重启 VS Code，配置使用本地 Ollama 或 DeepSeek API。

配置 API Key（可选）

如果使用云端 API（如 DeepSeek），运行 aihub config set deepseek sk-你的Key 进行配置。

开始使用

Ollama: 运行 ollama run qwen2.5:7b 开始对话。
Continue: 在 VS Code 中按 Ctrl+L 打开 AI 对话。
AnythingLLM: 打开应用，导入文档开始提问。

8 常见问题

点击问题展开答案。

没有技术基础能用吗？
完全可以。只需要复制一行命令粘贴到终端，安装器会自动处理所有技术细节。就像安装 QQ 一样简单。
8GB 内存够用吗？
够用。选择 qwen2.5:3b 模型（仅需约 2GB 内存）或 qwen2.5:7b（约 4.7GB）。运行时会比较占内存，建议关闭其他大型软件。
没有 NVIDIA 显卡能用吗？
可以。Ollama 支持 CPU 推理，没有 GPU 也能运行，只是速度慢一些（大约每秒生成 5-10 个字）。有 NVIDIA 显卡会快 10 倍以上。
下载速度太慢怎么办？
安装器已默认使用国内镜像。如果还是慢：检查网络连接、尝试切换网络（手机热点）、避开晚高峰。Ollama 模型下载可以断点续传。
PowerShell 提示"无法加载脚本"？
运行以下命令允许脚本执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
安装后找不到命令？
重启终端。如果还不行，Windows 检查 C:\Program Files\nodejs 是否在 PATH 中。macOS/Linux 在 ~/.bashrc 中添加 export PATH="$PATH:/usr/local/bin"。
如何卸载？
卸载单个工具：aihub uninstall ollama
卸载所有：rm -rf ~/.ai-installer-hub（Windows: Remove-Item -Recurse -Force "$env:USERPROFILE\.ai-installer-hub"）
数据会上传到云端吗？
使用本地模型（Ollama）时，所有数据都在你的电脑上，不会上传任何地方。使用云端 API（如 DeepSeek）时，你的对话内容会发送到对应的服务商。
需要花钱吗？
不需要。Ollama（本地模型）完全免费，Continue 插件免费开源，搭配使用就是免费的 AI 编程助手。如果想要更好的效果，DeepSeek API 也很便宜（几毛钱一次对话）。
